# StoryCraft AI

A Storybot ai that can make stories using Your images.

# Dependencies

A PC or laptop
Node.Js
Visual Studio Code

# Usage

Copy this command in your Terminal

```
git clone https://github.com/Mxfil-G/StoryCraft-AI
```
(Requires Git)

Go to the installed directory

```
cd StoryCraft-AI
```
Install Dependencies
```
npm install
```
Open Visual Studio Code

Install the Rick Astley's Live Server Extension

Go to index.html

Run the Live extension

And now you have it, Here is the guide video
