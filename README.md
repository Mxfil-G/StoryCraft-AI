# StoryCraft AI

A Storybot ai that can make stories using Your images.

# Dependencies

A PC or laptop
Node.Js

# Usage

Copy this command in your Terminal

```
git clone https://github.com/Mxfil-G/StoryCraft-AI
```
(Requires Git)

Go to the installed directory

```
cd StoryCraft-AI
```
Install Dependencies
```
npm install
```
Edit the .env.local(.env.local) 

Run the App

```
npm run dev
```

And now you have it
